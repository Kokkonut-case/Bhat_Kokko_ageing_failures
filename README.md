# Code for Bhat and Kokko, "Stochastic failure accumulation as a foundation for exponential mortality and selective disappearance"

This repo contains scripts required to replicate the figures presented in the main text of "Stochastic failure accumulation as a foundation for exponential mortality and selective disappearance" by Bhat and Kokko, 2026.

- `fig_2AB.r` reproduces Figure 2A and Figure 2B. These figures compare logistic failure accumulation + geometric mortality and logistic failure accumulation + linear mortality for the Tithonus model with a Gompertz-Makeham curve. The output is stored as SVG in the `output` folder.
- `fig_2CD.r` reproduces Figure 2C and Figure 2D. These figures compare the expected behaviour of the Tithonus model for various finite values of N with the expected behaviour for infinite N. The output is stored as SVG in the `output` folder.
- `disappearance_ssa.r` simulates our exact main model (a birth-death process with state-dependent killing) using the Gillespie algorithm. The output is stored as a CSV file in `output/ssa_data/`.
- `fig_3.r` reproduces Figure 3A and 3B. This figure compares the output of the Gillespie simulations generated by `disappearance_ssa.r` with the analytical predictions made from the Tithonus model using the Feynman-Kac formula. The output is stored as SVG in `output/feynmankac_plots/`.
- `fig_4.r` reproduces Figure 4A and Figure 4B. This figures solves the Tithonus SDE and uses Feynman-Kac formulae to compute expected survivorship when the deviation from Gompertz-Makeham first exceeds various fixed thresholds.  The output is stored as SVG in the `output` folder.
- `fig_S2.r`reproduces Figure S2 of the supplementary. This figure is a version of Figure 4 for a set of different parameter values, intended to illustrate the robustness of the results of figure 4.
